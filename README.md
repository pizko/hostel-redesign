# Like Home — редизайн «Линия»

Радикальный редизайн https://likehome-hostel.ru/ — Urban Industrial × Swiss Typography. **Прототип, не production.**
Контент — только с оригинального сайта, дословно; дизайн и вёрстка — новые. Подробности, источники и противоречия — `docs/AUDIT.md`.

## Концепция
Сквозной мотив — линия маршрута от МЦД Новодачная: каждый раздел — «остановка» с номером (01–09), шаги оформления — станции на линии,
локация — собственная схема пути (без символики МЦД). Подтверждённые цифры (от 599 ₽, 30 дней, 1 комната, 8·10·12 мест) — крупные
типографические объекты на табло. Графит + тёплый белый, лайм — единственный сигнальный цвет. Inter Tight / Inter / IBM Plex Mono.

## Сборка
```sh
python3 tools/extract.py     # тексты из снимка source/pages → data/pages.json
python3 build.py             # предпросмотр в dist/: noindex, без Метрики
python3 build.py --prod      # боевая сборка: index, Метрика 88450058, robots/sitemap оригинала
python3 tools/serve.py 8790  # http://127.0.0.1:8790 — /rooms отдаётся как rooms.html, как на хостинге
```

## Структура
- `build.py` — генератор всех 17 страниц
- `assets/css/site.css`, `assets/js/site.js` — дизайн-система и интерактив без библиотек
- `data/facts.json` — проверенные факты с источниками; `data/pages.json` — тексты страниц
- `source/` — снимок оригинала (доказательная база контента)
- `tools/check.html` — проверка скролла, H1, картинок и ссылок на 360/390/768/1440/1920
